# RF-Vision-UAV-Tracker-RA8P1

RT-Thread firmware for the downgraded RA8P1 edge terminal version of the
RF-Vision-UAV-Tracker system.

The Orange Pi 5 system keeps the high-performance pipeline, map UI, database,
and multi-sensor fusion. This RA8P1 project is the lightweight terminal that
stays near the SDR front-end, performs basic RF pre-detection, and reports
compact events to a center host over Ethernet or 5G.

See `RF-Vision-UAV-Tracker-RA8P1/docs/ra8p1_migration_plan.md` for the migration
plan and firmware module layout.
